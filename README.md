# fontfinder
Photoshop açmadan PSD dosyalarındaki metin katmanlarını tarayan; font adlarını, yapay stilleri (faux bold/italic) ve gelişmiş tipografi ayarlarını anında çözümleyen web tabanlı akıllı Font Ayrıştırıcı (Font Parser). TypeR entegrasyonu ve yönetim paneli (Nextcloud) depo desteğiyle birlikte.
